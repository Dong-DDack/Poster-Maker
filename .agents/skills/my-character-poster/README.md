# My Character Poster

한국어 행사 포스터를 위한 개인화된 Codex 스킬 프로토타입입니다. 캐릭터 설정, 반복 사용 가능한 디자인 기본값, 스타일 선택, 정보 우선순위, 편집 가능한 HTML 글자를 다룹니다.

## 사용

이 폴더를 프로젝트의 `.agents/skills/` 아래에 둔 뒤 Codex에서 `$my-character-poster`를 호출합니다. 이미지 생성 기능이 제공되는 Codex 환경이 필요합니다. 이 스킬에는 자체 이미지 생성 모델이나 API 키가 포함되어 있지 않습니다.

`EXTEND.md`에서 기본 스타일, 색상, 비율을 원하는 대로 바꿀 수 있습니다. 캐릭터를 반복 사용하려면 생성된 포스터 폴더의 `character.md`를 유지하고 다음 작업 때 참고 이미지와 함께 제공합니다.

## 원본 참고 및 라이선스

이 프로토타입은 [howardz27/poster-generator-skill](https://github.com/howardz27/poster-generator-skill)의 정보 정리 → 스타일 선택 → 프롬프트 생성 → 렌더링 흐름을 참고해 한국어 포스터와 캐릭터 일관성에 맞게 재구성했습니다. 원본은 MIT 라이선스이며 원 저작권 고지는 [LICENSE](LICENSE)에 보존했습니다.
