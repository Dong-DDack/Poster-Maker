# Character profile template

Create one `character.md` per recurring character in a poster output folder. Keep descriptions concrete and stable.

```markdown
# Character name
- Role/personality:
- Species or visual type:
- Silhouette and proportions:
- Face, eyes, and expression range:
- Main colors (hex if known):
- Signature details that must stay:
- Outfit rules:
- Allowed pose/expression changes:
- Avoid changing:
- Reference image path and rights/permission notes:
```

For each new poster, copy the identity fields into the image prompt and attach the reference image if available. Vary pose, emotion, clothing, and scene only within the stated rules. If the reference image cannot be sent to the renderer, say that character consistency may be weaker and use the written profile.
