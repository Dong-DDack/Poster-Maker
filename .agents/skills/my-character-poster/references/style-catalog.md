# Style choices

Offer these as plain-language choices. A saved `EXTEND.md` preference takes priority; otherwise choose the best fit for the brief.

- **Cute illustration** — rounded shapes, expressive mascot, warm palette, approachable event feel.
- **Retro editorial** — print grain, limited inks, bold geometric type, nostalgic campaign feel.
- **Minimal** — generous whitespace, restrained colors, strong typographic hierarchy.
- **Magazine collage** — layered cutouts, paper textures, dynamic editorial composition.
- **Bright commercial** — crisp contrast, clear information blocks, polished promotional energy.
- **Character key art** — cinematic lighting and a strong character pose; keep event details in a separate clean text area.

The style describes visual treatment, not a request to imitate a named living artist or copy another poster. If the user supplies reference designs, identify general attributes such as palette, density, and geometry rather than tracing the exact composition.
